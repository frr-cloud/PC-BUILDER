Glosario de Hardware

Conceptos clave explicados de forma sencilla para entender las especificaciones técnicas.

BIOS / UEFI

Sistema básico de entrada/salida almacenado en la placa base que se encarga de inicializar el hardware al encender el equipo y cargar el sistema operativo.

TDP (Thermal Design Power)

Medida expresada en vatios (W) que representa la cantidad máxima de calor que genera un componente y que el sistema de refrigeración debe ser capaz de disipar.

PCIe (Peripheral Component Interconnect Express)

Bus de expansión de alta velocidad utilizado para conectar tarjetas gráficas, unidades SSD NVMe y otras tarjetas adicionales a la placa base.

VRM (Voltage Regulator Module)

Circuito en la placa base encargado de regular y limpiar el voltaje que recibe el procesador desde la fuente de alimentación para garantizar su estabilidad.
